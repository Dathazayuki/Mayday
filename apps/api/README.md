# @drmayday/api

API NestJS 12 của DrMayDay (tiền tố `/api/v1`, Swagger ở `/api/v1/docs`).

Hướng dẫn cài đặt và chạy: [README ở thư mục gốc](../../README.md). Tài liệu chuẩn: [docs/README.md](../../docs/README.md).

```bash
pnpm --filter @drmayday/api start:dev   # chạy dev
pnpm --filter @drmayday/api test        # unit test
pnpm --filter @drmayday/api test:e2e    # e2e test
```
