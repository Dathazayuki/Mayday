### get_uas7scores_eligibility (uas701)

- Tab Sheet: [`GET /api/uas7-scores/eligibility`](https://docs.google.com/spreadsheets/d/162s8pbiP7WhOwSDWopc11hK3Qp-CBYF19qv25ShMKCA/edit#gid=1223801917)
- Đường dẫn ghi trong slide: `GET /api/v1/uas7-scores/eligibility`
- Ảnh slide 5: Ảnh slide đã đối chiếu với Sheet ngày 14/11/2026: khớp.

Mô tả trong Sheet: Bảng đặc tả Input và Output chi tiết cho API kiểm tra điều kiện làm bảng chấm điểm UAS7:

**Input**

| STT | Tham số | Kiểu | NN | Mô tả |
|---|---|---|---|---|
| 1 | `Authorization` | string | O | Header truyền Bearer Token của Admin |

**Output**

| STT | Tham số | Kiểu | NN | Mô tả |
|---|---|---|---|---|
| 1 | `code` | string | O | Mã phản hồi (1000: Thành công) |
| 2 | `message` | string | O | Thông báo kết quả |
| 3 | `data` | object | O | Kết quả kiểm tra điều kiện |
|  | ↳ `eligible` | string | O | Trạng thái đủ điều kiện hay không (Trả về chuỗi "true" hoặc "false") |
|  | ↳ `medical_record_id` | string | X | ID hồ sơ bệnh án đang active (Nếu eligible là "true") |

#### Mô tả uas701

- API thực hiện việc kiểm tra xem bệnh nhân hiện tại có đang sở hữu hồ sơ bệnh án nào hợp lệ (đang active) để được phép thực hiện chấm điểm UAS7 hay không.
- Request dạng GET (/api/v1/uas7-scores/eligibility).
- Backend chú ý: Dù giá trị trả về mang tính logic đúng/sai, nhưng toàn bộ kiểu dữ liệu response trả về phải được format thành dạng string (VD: "true", "false", "5") theo yêu cầu hệ thống hiện tại.
- _(slide 6)_

#### Các test case cho uas701

- Bệnh nhân có bệnh án đang trong quá trình điều trị.
- Kết quả mong đợi: Mã 1000 | OK. Trả về eligible: "true" kèm theo medical_record_id dạng chuỗi.
- Bệnh nhân không có bệnh án hoặc bệnh án đã đóng (completed).
- Kết quả mong đợi: Mã 1000 | OK. Trả về eligible: "false".
- _(slide 7)_

### create_uas7scores (uas702)

- Tab Sheet: [`POST /api/uas7-scores/`](https://docs.google.com/spreadsheets/d/162s8pbiP7WhOwSDWopc11hK3Qp-CBYF19qv25ShMKCA/edit#gid=2059182507)
- Đường dẫn ghi trong slide: `POST /api/v1/uas7-scores`
- Ảnh slide 9: Ảnh slide đã đối chiếu với Sheet ngày 14/11/2026: khớp.

Mô tả trong Sheet: Bảng đặc tả Input và Output chi tiết cho API Bệnh nhân gửi điểm UAS7 hàng ngày:

**Input**

| STT | Tham số | Kiểu | NN | Mô tả |
|---|---|---|---|---|
| 1 | `Authorization` | string | O | (Header) Truyền Bearer Token xác thực |
| 2 | `Content-Type` | string | O | (Header) Mặc định là application/json |
| 3 | `medical_record_id` | string | O | ID hồ sơ bệnh án liên quan |
| 4 | `score_date` | string | O | Ngày chấm điểm (Định dạng chuỗi "YYYY-MM-DD") |
| 5 | `iss7` | string | O | Điểm số mảng sẩn tích luỹ (Itch/Wheal Severity Score - truyền chuỗi số VD: "2") |
| 6 | `hss7` | string | O | Điểm số mức độ ngứa tích luỹ (Histamine/Itch Severity Score - truyền chuỗi số VD: "1") |
| 7 | `note` | string | X | Ghi chú thêm của bệnh nhân |

**Output**

| STT | Tham số | Kiểu | NN | Mô tả |
|---|---|---|---|---|
| 1 | `code` | string | O | Mã phản hồi (1000: Thành công) |
| 2 | `message` | string | O | Thông báo kết quả |
| 3 | `data` | array | O | Mảng danh sách các bản ghi điểm UAS7 của bệnh nhân |
|  | ↳ `patient_id` | string | O | ID bệnh nhân |
|  | ↳ `medical_record_id` | string | O | ID hồ sơ bệnh án |
|  | ↳ `score_date` | string | O | Ngày chấm điểm |
|  | ↳ `iss7` | string | O | Điểm mảng sẩn |
|  | ↳ `hss7` | string | O | Điểm mức độ ngứa |
|  | ↳ `daily_score` | string | O | Điểm tổng trong ngày |
|  | ↳ `note` | string | X | Ghi chú |
|  | ↳ `created_at` | string | O | Thời điểm tạo |
|  | ↳ `updated_at` | string | O | Thời điểm cập nhật |

#### Mô tả uas702

- API cho phép bệnh nhân ghi nhận điểm số mề đay UAS7 hằng ngày (bao gồm điểm sẩn - ISS7 và điểm ngứa - HSS7).
- Request dạng POST (/api/v1/uas7-scores).
- Backend chú ý: Dữ liệu lưu vào bảng uas7_scores. BE cần tự động parse các trường iss7, hss7 từ string sang int để tính toán daily_score (tổng điểm trong ngày) trước khi lưu DB. Phải validate ràng buộc UNIQUE(patient_id, score_date) để tránh bệnh nhân ghi trùng điểm trong cùng 1 ngày.
- _(slide 10)_

#### Các test case cho uas702

- Bệnh nhân gửi điểm số hợp lệ cho ngày hôm nay.
- Kết quả mong đợi: Mã 1001 | Created successfully. Trả về thông tin bản ghi vừa tạo.
- Bệnh nhân đã submit điểm cho ngày hôm nay rồi nhưng cố tình gọi API gửi lại.
- Kết quả mong đợi: Mã lỗi 5002 | Score for date already submitted. Bị chặn bởi ràng buộc UNIQUE trong CSDL.
- Bệnh nhân truyền giá trị iss7 hoặc hss7 nằm ngoài khoảng cho phép (từ "0" đến "3").
- Kết quả mong đợi: Mã lỗi 5003 | Invalid ISS7 value hoặc 5004 | Invalid HSS7 value.
- _(slide 11)_

### GET /api/uas7-scores/week/:patientId

- Tab Sheet: [`GET /api/uas7-scores/week/:patientId`](https://docs.google.com/spreadsheets/d/162s8pbiP7WhOwSDWopc11hK3Qp-CBYF19qv25ShMKCA/edit#gid=1548845498)

Mô tả trong Sheet: Bảng đặc tả Input và Output chi tiết cho API Tính tổng và đánh giá mức độ nặng điểm tuần UAS7:

**Input**

| STT | Tham số | Kiểu | NN | Mô tả |
|---|---|---|---|---|
| 1 | `Authorization` | string | O | Header truyền Bearer Token của Admin |
| 2 | `patient_id` | string | O | Id của bệnh nhân cần tra cứu lịch sử |
| 3 | `start_date` | string | X | Ngày bắt đầu tính tuần (YYYY-MM-DD, mặc định là 7 ngày gần nhất) |

**Output**

| STT | Tham số | Kiểu | NN | Mô tả |

| 1 | `code` | string | O | Mã phản hồi hệ thống (1001 hoặc 1000: Thành công) |
| 2 | `message` | string | O | Thông báo kết quả (Created successfully) |

|  | ↳ `patient_id` | string | O | ID bệnh nhân |
|  | ↳ `week_score` | string | O | Tổng điểm UAS7 trong tuần (Tổng các ngày, tối đa 42 điểm) |
|  | ↳ `severity_label` | string | O | Nhãn đánh giá mức độ bệnh (VD: "Không có", "Nhẹ", "Trung bình", "Nặng") |
|  | ↳ `completed_days` | string | O | Số ngày đã hoàn thành chấm điểm trong chu kỳ 7 ngày |
